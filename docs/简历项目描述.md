## 简历 Bullet Points（3-4 条，任选组合）

**全面版（适合项目经历栏）：**

- **NucleiAI — AI 增强漏洞管理平台** | Python, FastAPI, Nuclei, Ollama | 2026.05
  - 在 Nuclei 扫描引擎之上构建 AI 误报过滤层，基于 Ollama 本地大模型实现批量语义分析，将扫描结果自动分类为真实漏洞/误报/技术识别
  - 设计**混合防线架构**（LLM 语义分析 + 5 条硬规则确定性修正），解决 8B 量化模型一致性问题，稳态准确率从 75% 波动提升至 90%+
  - 自建 20 端点漏洞靶场（14 漏洞 + 6 误报干扰），编写 20 个 Nuclei YAML 检测模板覆盖 OWASP Top 10，全链路扫描+AI 分析耗时 ~3 分钟
  - 实现指纹识别驱动的智能模板选择、两次扫描结果 Diff 对比、一键中文安全报告生成
  - 扩展真实网站扫描能力：BFS 爬虫 + 登录态会话管理（Cookie/Bearer）+ 子域名资产发现 + 全自动管线；支持本地 Ollama 与 OpenAI 兼容 API 双 LLM 后端；面板访问令牌鉴权 + pytest 22 例 + GitHub Actions CI
