# NucleiAI 演示视频脚本（约 3 分钟）

## 准备

- 启动 Ollama（确保 qwen3:8b 已加载）
- 或配置云 LLM：`$env:NUCLEIAI_LLM_API_KEY` + `$env:NUCLEIAI_LLM_BASE_URL`（DeepSeek 等）
- 可选：`$env:NUCLEIAI_AUTH_TOKEN = "xxx"` 演示面板鉴权
- 启动漏洞靶场：`cd test-target && python vuln_server.py 9999`
- 启动 Web 面板：`python -m uvicorn web.app:app --host 127.0.0.1 --port 8080`（或 `python run.py`）
- 浏览器打开 `http://127.0.0.1:8080`

## 场景一：全流程扫描（60秒）

**旁白**："这是 NucleiAI——一个 AI 增强的漏洞管理平台。我来演示一次完整的扫描流程。"

1. 输入目标 URL：`http://127.0.0.1:9999`
2. 点击"开始扫描"
3. 等待约 1 分钟（展示扫描进度）

**旁白**："扫描引擎是 Nuclei，它用 20 个自定义模板检测 OWASP Top 10 漏洞。同时 httpx 自动识别目标技术栈，智能选择额外的官方检测模板。"

4. 扫描完成，展示结果页面

**旁白**："26 条检测结果。看看 AI 的分析——每条都有判定类型、置信度和中文理由。比如这个 SQL 注入错误泄露，AI 判定为真实漏洞，置信度 95%。"

## 场景二：误报过滤展示（40秒）

**旁白**："自动扫描器的最大痛点是误报。来看看 AI 怎么处理的。"

1. 滚动到误报区，展示被过滤的结果

**旁白**："这个安全教程页包含了 `<script>` 代码示例，触发了 XSS 检测模板。但 AI 识别出它是教学文章，正确标记为误报。再看这个——重定向目标被硬规则修正为内部路径，自动标误报。"

2. 展示 AI 摘要区（确认数 vs 误报数）

## 场景三：智能扫描 + 指纹识别（30秒）

**旁白**："回到顶部，可以看到指纹识别结果——目标服务器是 Apache，技术栈包含 PHP。系统根据指纹自动从 Nuclei 官方模板库中匹配了 2 个相关模板，不用扫描全部几千个模板。"

1. 指向指纹区域和技术栈标签
2. 指向"智能匹配 2 模板"

## 场景四：扫描 Diff 对比（30秒）

**旁白**："修复漏洞后如何验证？跑两次扫描，用 Diff 对比。"

1. 使用对比功能，选择两次扫描结果
2. 点击"对比"
3. 展示三栏：已修复 / 新增 / 持续存在

**旁白**："一目了然——哪些漏洞修好了，哪些是新的，哪些还在。"

## 场景五：中文报告（20秒）

**旁白**："最后看看报告功能。"

1. 点击"查看报告"
2. 展示报告页面（严重度分布、AI 安全摘要、优先修复建议）

**旁白**："一键生成中文安全报告，包含 AI 摘要和修复优先级，可以直接交付给客户。项目用了 Python FastAPI + Ollama 本地部署，2000+ 行代码，完全开源。"

## 结尾

"项目地址在 GitHub，欢迎 Star 和交流。谢谢观看。"

## 场景六：资产发现 + 管线扫描（40秒，可选）

**旁白**："如果只有一个根域名，NucleiAI 可以自动做资产发现——从证书透明日志枚举子域名，探测存活主机，然后自动逐个扫描并用 AI 过滤。"

1. 在"资产发现"输入根域名（演示用测试域名或你自己的授权域名）
2. 展示子域名列表和存活主机
3. 点击"管线扫描"，展示全自动流水线结果

**旁白**："爬取加会话功能还支持登录态扫描：把登录后的 Cookie 或 Bearer Token 填进去，就能扫描需要认证的页面，这是真实渗透里最常见的场景。"

## 场景七：面板鉴权（15秒，可选）

**旁白**："工具本身也是安全产品——设置访问令牌后，面板需要登录才能使用，避免本机工具被其他人驱动去扫描任意目标。"

1. 设置 `NUCLEIAI_AUTH_TOKEN` 后重启
2. 展示未登录跳转登录页，输入令牌进入

## 录制建议

- 使用 OBS 或 Windows 自带录屏（Win+G）
- 分辨率 1920×1080
- 配音或字幕均可
- 可以加快扫描等待部分的播放速度（1.5x-2x）
- 提前准备好环境，避免等待时间过长
